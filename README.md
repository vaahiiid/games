# Quiet Corners

Small calming games for when you're stressed, angry, or just need ten quiet minutes.
No scores, no timers, no losing. The only goal is to feel a little calmer.

| Game | Good for |
| --- | --- |
| [Firefly Lake](firefly-lake/) | Racing thoughts: gentle focus, kind words, breathing |
| [Shy Sheep Hill](shy-sheep-hill/) | Feeling tense or angry: patience and slow movement |
| [Moss & Sand](moss-and-sand/) | Restlessness: raking a Japanese dry garden through four seasons |

Each game is a single self-contained HTML file. Anything a game saves (your flock, your gardens) stays in your own browser.

More games will be added over time.
